# File Reference

What every file in the repository does. `package-lock.json` is generated by npm and should not be edited by hand. For how the parts work together, see the [project guide](PROJECT-GUIDE.md).

## Repository root

| File                      | Purpose                                                                                   |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| `README.md`               | Project summary, quick start, demo login and common commands                              |
| `package.json`            | Root workspace definition, shared dev tools and the main npm scripts                      |
| `package-lock.json`       | Exact resolved dependency versions                                                        |
| `tsconfig.base.json`      | Strict TypeScript options and `@lumio/*` path aliases shared by every workspace           |
| `tsconfig.json`           | Type-checks packages, backend and worker together. Emits nothing                          |
| `vitest.config.ts`        | Defines the `unit`, `integration` and `frontend` test projects                            |
| `playwright.config.ts`    | Browser test settings. Reads `E2E_BASE_URL`                                               |
| `eslint.config.js`        | Lint rules, including a ban on floating-point helpers in the calculation engine           |
| `.prettierrc.json`        | Formatting rules                                                                          |
| `.prettierignore`         | Files Prettier skips                                                                      |
| `.dependency-cruiser.cjs` | Architecture rules: no cycles, modules only through `index.ts`, a pure calculation engine |
| `.env.example`            | Template of every environment variable                                                    |
| `.gitignore`              | Files kept out of git, including `.env` and build output                                  |
| `.dockerignore`           | Files kept out of Docker build contexts                                                   |
| `.npmrc`                  | Saves exact versions and enforces the Node version                                        |
| `.nvmrc`                  | Node major version (22)                                                                   |
| `docker-compose.yml`      | Full development stack, plus the `seed` and `scan` profiles                               |
| `docker-compose.prod.yml` | Production app containers, hardened. MongoDB and Redis are external                       |
